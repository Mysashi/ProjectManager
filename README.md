## Краткое описание проекта
Веб-приложение для организации командной работы, позволяющее структурировать задачи внутри проектов и гибко управлять составом участников.

## Стек технологий
Интеграции и инструменты: REST + WebSockets

Стек технологий:

  Backend: Java 21,Spring Boot 4.0.3,Hibernate 7.0+, Jakarta 11
  
  Тестирование: Spring tests, Rest-assured
  
Документация: Автоматическая генерация API-документации через Swagger, Javadoc, README.MD
